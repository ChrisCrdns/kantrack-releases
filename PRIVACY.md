# KanTrack Privacy Policy

Effective date: May 10, 2026

KanTrack is a local-first macOS task board. It is designed to work without an account, cloud service, ads, analytics, or tracking.

## Data Collection

KanTrack does not collect, transmit, sell, rent, or share personal data.

KanTrack does not use third-party analytics, advertising SDKs, tracking SDKs, or crash-reporting services.

## Local Data

Tasks, lanes, notes, tags, priorities, settings, and other board data are stored locally on your Mac using the app's local storage.

KanTrack does not send this board data to KanTrack, the developer, Apple, or any third party.

## Import and Export

KanTrack lets you export and import board data as JSON files. These actions are initiated by you and use files you select.

You are responsible for where exported files are saved and how they are shared.

## Launch at Login

In the Mac App Store version, Launch at Login is off by default. If you enable it, KanTrack uses Apple's Service Management API to register the app as a login item. You can turn this off in KanTrack settings or in macOS System Settings.

## Network Use

The Mac App Store version of KanTrack does not include an auto-updater and does not contact a KanTrack server.

The Privacy Policy and Support buttons open your web browser to public GitHub pages only when you click them.
